# 整合包 · 个人助理

> 示例整合包。格式见 [../../开发文档.md](../../开发文档.md)。
> **本文只写：由哪些插件完成。**

## 1. 目标

记住你是谁、你要什么，**并在事情来得及之前告诉你**。

**沉淀型整合包** —— 前面四个都是**用户发起**，这个是**系统主动**。它大部分时间不在对话里，在守候。

```text
语音助手（入口型，说完就走） → 个人助理（沉淀型，记着并跟进） → 到点提醒
```

### 1.1 模型策略

```ts
modelPolicy: {
  transport: "api",
  byTaskKind: {
    remind:  ["claude-haiku-4-5"],  // 到点提醒是模板活
    summarize:["claude-haiku-4-5"],// 长期对话压缩成一句摘要
    judge:   ["claude-sonnet-5-5"],// 判断该不该现在提醒
  },
}
```

**这个包的成本敏感度最高** —— 它**系统主动**发起，而且大部分时间在守候，不在对话里。`remind` / `summarize` 都是高频体力活，用最便宜的模型。

`judge` 换强一点：判断"这件事现在提醒你合不合适"是个取舍题，便宜模型容易变成无差别轰炸。

`transport: "api"`：提醒是定时任务，不是交互式对话，外部 CLI 那个 CLI 会话只会白白占着配额。

## 3. 套件

| 套件 | 用它做什么 | 离线时 |
|---|---|---|
| `model-suite` | 记忆抽取、压缩、归纳 | 用 `local-model` |
| `notify-suite` | 多通道提醒推送（应用内/邮件/短信） | 只在会话内提醒 |
| `memory-cloud` | 云端向量检索 | **本地检索** |

> **`memory-cloud` 是可选项，不是默认。** 记忆默认留在本地。上云要你显式开。

## 4. 主动但不打扰

**这是本整合包成立与否的关键。** 主动浮现做过头就是灾难，所以规则写死：

| 规则 | 说明 |
|---|---|
| 只在**过时不提醒就来不及**时打断 | 想起来说两句不叫打扰 |
| 同一件事**最多提醒 3 次** | 第 4 次转静默记录 |
| 提醒必须**带可执行动作** | 不发"你可能需要休息"这种废话 |
| 不确定你是否还在意 → **静默记录代替打断** | 记下来，你问起再提 |
| 静默不打扰也**进日志埋点** | 你事后能查到"本来想提醒你" |
| 打扰预算按天算 | 超预算的降级为静默，不硬发 |
| 后台不刷屏 | 一次提醒合并多条同类 |

**事后可查**是关键：你不被打扰，但你随时能问"这周你本来想告诉我什么"。

## 5. 状态与模式

状态仍是标准五态（[../../开发文档.md §3](../../开发文档.md)），但本包多一个**运行模式**：

```text
模式: 前台（你在对话） | 后台（守候）
状态: 讨论 → 计划 → 工作 → 微调修正 → 汇报
```

| 模式 | 在做什么 | 触发 |
|---|---|---|
| **后台** | 守候、预取、监测目标进度与日程 | 装载后常驻 |
| **前台** | 讨论/计划/工作/微调修正/汇报 | 你说话，或提醒触发 |

**后台不做"工作"态的事** —— 不改代码、不发 outward 动作。后台只做三件事：预取、监测、到点提醒。

**这条边界很重要**：后台一旦开始"工作"，你不知道它在干什么，也拦不住。

## 6. 交接

### ← 语音助手（主路径）

说完需求就走，不必陪着：

```ts
{
  targetPackageId: "personal-assistant",
  trigger: "完成条件",
  requiredFacts: ["objective", "preferences", "schedule"],
  handoffMapping: {
    "task.objective":       "goal.draft",          // 先进草稿，不直接立为长期目标
    "task.decisions":       "profile.candidates",  // 偏好进候选，等你确认
    "task.nextActions":     "goal.nextActions",
    "task.constraints":     "goal.constraints",
  },
  prepare: [
    { kind: "promptRules",  value: "personal-assistant/default" },
    { kind: "reportFormat", value: "personal-assistant/assistant-report" },
    { kind: "mode",         value: "后台" },
  ],
}
```

**交接过去的东西默认是草稿。** 长期目标和档案事实都要你确认 —— 助理不能自己决定"这就是你的长期目标"。

### → 代码开发

研究一个主题后要落地成东西时。

### → 项目监测

目标关联到已有项目后，进度自动进监测。

### → 语音助手

需要你**当场**答一句才能往下走时（冲突记忆、授权、决策），推一条语音提醒过去。

## 7. 汇报格式

```ts
{
  id: "personal-assistant/assistant-report",
  sections: [
    { key: "completed", title: "完成了什么",     required: true },
    { key: "issues",    title: "存在什么问题",   required: true },
    { key: "decisions", title: "需要我做什么决策", required: true },
    { key: "when",      title: "什么时候前要处理", required: true },  // 时效
  ],
  requireEvidence: false,
  outputFormat: "markdown",      // 可切 "voice" 走 TTS
}
```

**第 4 段"时效"是本包特有的** —— 助理的每条输出都必须回答"什么时候前要做"。没时效的提醒不进汇报。

## 8. 权限与事前授权

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:read` `fs:write` | 记忆与目标落盘 | 是 |
| `net` | 模型调用、查信息 | 是 |
| `device` | 截屏、框选 | 否 |

**后台主动执行无法逐次询问，所以要事前授权**。这是本包和前四个包最大的不同：

| 情形 | 做法 |
|---|---|
| 读取类（查信息、读网页） | 免确认，直接做 |
| 发送类（邮件、日程） | **事前授权**：范围 + 有效期 |
| 承诺类（购买、预订、议价） | **默认不装载**。要装必须逐项 + 逐次授权 |
| 授权过期 | 按拒绝处理，转为提醒你 |

`action-authorize` 不可用时，**停止所有主动执行，只做提醒**。

## 9. 降级

| 缺失 | 行为 |
|---|---|
| 记忆系统全不可用 | **退化为无记忆助理**，只做当前窗口，**明确告知已失忆** |
| `action-authorize` 不可用 | 停止所有主动执行，**只提醒不做** |
| `memory-cloud` 离线 | 本地检索，召回质量下降，**明确告知** |
| `notify-suite` 离线 | 只在会话内提醒，**明确告知推送不可用** |
| `model-suite` 离线 | `local-model`，抽取与压缩质量下降 |
| 预取超时 | **不阻塞主对话**，静默跳过 |
| `mem-reconcile` 不可用 | 新旧冲突时**不注入任何一方**，等你确认 |
| 后台预取占满资源 | 自动降到低频，**明确告知频率变了** |

## 10. 验收

- [ ] 记下的偏好**只有你明确说过的**，没有从行为反推的
- [ ] 记忆是**每轮自动浮现**的，不需要你主动检索
- [ ] 无关键词匹配时也能浮现（考试↔压力 这类联想有效）
- [ ] 注入超预算时**明示截断**，不悄悄少给
- [ ] 热记忆和冷知识**结果标明来源**，不混为一谈
- [ ] 每条召回都说得出**为什么想起它**
- [ ] 记忆能看、能改、能删、能导出
- [ ] 删除有备份期且**明确告知备份期多长**
- [ ] 长期目标和档案事实**默认进草稿，要你确认**
- [ ] 记忆矛盾时并存标记 + 问你，**不自动覆盖**
- [ ] 提醒只打断"过时不提醒就来不及"的事
- [ ] 同一件事最多提醒 3 次，之后转静默
- [ ] 静默没提醒的**事后能查到**
- [ ] **后台绝不执行 outward 动作**，除非有事前授权
- [ ] `action-authorize` 挂了 → 立刻停止主动执行
- [ ] 换窗口后记忆和目标都接得上
- [ ] 汇报恒为三段 + 时效
