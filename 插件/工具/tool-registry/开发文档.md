# 插件 · 工具注册与类别展开

| 项 | 值 |
|---|---|
| `id` | `tool-registry` |
| 所属分类 | 工具 |
| 风险级别 | safe（无风险） |
| 依赖插件 | 无 |
| 状态 | ⬜ 待开发 |

## 1. 目标

整合包按**类别**申请工具，运行时展开为具体工具。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "tool-registry",
  version: "0.1.0",
  description: "整合包按**类别**申请工具，运行时展开为具体工具。",
  capabilities: [/* 见 §4 */],
  permissions: [],
  requires: [],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `register(manifest) => void`
- `resolve(categories, grant) => ToolGrant`
- `healthCheck(id) => HealthReport`
- `unregister(id) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| — | 不需要权限 | — |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 工具离线 | 标记不可用，**不静默跳过** |
| 权限不足 | 在 denied 中带原因返回 |
| 类别展开为空 | 明确告知该类别无可用工具 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 整合包按类别申请，不逐个列举
- [ ] **denied 必须带原因，不返回空数组**
- [ ] 风险级别与权限判断相互独立
- [ ] 工具增减不影响整合包清单

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
