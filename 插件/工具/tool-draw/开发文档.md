# 插件 · 绘画工具

| 项 | 值 |
|---|---|
| `id` | `tool-draw` |
| 所属分类 | 工具 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `fs` |
| 状态 | ⬜ 待开发 |

## 1. 目标

图像生成、SVG 绘制。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "tool-draw",
  version: "0.1.0",
  description: "图像生成、SVG 绘制。",
  capabilities: [/* 见 §4 */],
  permissions: ["net", "fs:write"],
  requires: ["fs"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `image(prompt, opts?) => ArtifactRef`
- `svg(spec) => ArtifactRef`
- `style(svgRef, style) => ArtifactRef`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 见目标所述用途 | 是 |
| `fs:write` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 生成服务不可用 | 明确告知，不返回占位图冒充 |
| 内容策略拦截 | 如实告知被拦截 |
| SVG 不合法 | 校验并拒绝 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] SVG 输出可校验
- [ ] 图像产出带参数记录
- [ ] **不返回占位图冒充真实产出**
- [ ] 生成物可追溯
- [ ] 产物标记待复核

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
