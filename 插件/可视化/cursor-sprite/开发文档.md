# 插件 · 鼠标精灵

| 项 | 值 |
|---|---|
| `id` | `cursor-sprite` |
| 所属分类 | 可视化 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `screen-capture context-chain` |
| 状态 | ⬜ 待开发 |

## 1. 目标

把上下文对象变成可拖的手柄。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "cursor-sprite",
  version: "0.1.0",
  description: "把上下文对象变成可拖的手柄。",
  capabilities: [/* 见 §4 */],
  permissions: ["device"],
  requires: ["screen-capture context-chain"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `bind(target) => Sprite`
- `drag(sprite, to) => DragResult`
- `unbind(sprite) => void`
- `render(sprite, mode) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `device` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 无图形环境 | 不可用并说明 |
| 目标不可接受 | 置灰并说明原因 |
| 拖放失败 | 回到原位并提示 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。
