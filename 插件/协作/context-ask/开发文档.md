# 插件 · 旁路问答

| 项 | 值 |
|---|---|
| `id` | `context-ask` |
| 所属分类 | 协作 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `context-chain` |
| 状态 | ⬜ 待开发 |

## 1. 目标

随心问随心答，**不打断**当前工作。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "context-ask",
  version: "0.1.0",
  description: "随心问随心答，**不打断**当前工作。",
  capabilities: [/* 见 §4 */],
  permissions: ["net"],
  requires: ["context-chain"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `ask(nodeIds, question) => Answer`
- `askAsync(nodeIds, question) => string`
- `onAnswer(cb) => void`
- `cancel(askId) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 无上下文可答 | 明确说无法回答 |
| 模型不可用 | 明确告知，不打断主流程 |
| 提问超时 | 异步返回，不阻塞 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 提问是旁路，**不中断当前任务流**
- [ ] 答案标明依据哪些节点
- [ ] 答不了就说答不了
- [ ] 可取消
- [ ] 提问不越权访问未授权内容

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
