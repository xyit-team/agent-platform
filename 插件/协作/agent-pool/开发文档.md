# 插件 · 智能体池

| 项 | 值 |
|---|---|
| `id` | `agent-pool` |
| 所属分类 | 协作 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `dispatch-llm` |
| 状态 | ⬜ 待开发 |

## 1. 目标

1–5 智能体动态决策，按维度分配。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "agent-pool",
  version: "0.1.0",
  description: "1–5 智能体动态决策，按维度分配。",
  capabilities: [/* 见 §4 */],
  permissions: ["net"],
  requires: ["dispatch-llm"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `sizing(task, ctx) => number`
- `allocate(spec) => AgentHandle[]`
- `release(handle) => void`
- `list() => AgentState[]`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 资源不足放不下 5 个 | 降到 1–3 并**说明降级原因** |
| 单 Agent 崩溃 | 该单元标失败，**其余继续** |
| 全部崩溃 | 任务失败，不静默无限重试 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 数量在 1–5 动态决定
- [ ] 可按视角/角色/专业/资历分配
- [ ] 单 Agent 崩溃不影响其他
- [ ] 释放后资源回收
- [ ] 分配决策有记录

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
