| 项 | 值 |
|---|---|

| 所属分类 | 协作 |

## 1. 目标

上下文是有序链，保留因果，支持编组共享。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "context-chain",
  version: "0.1.0",
  description: "上下文是有序链，保留因果，支持编组共享。",
  capabilities: [/* 见 §4 */],
  permissions: ["fs:write"],
  requires: ["fs"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `append(entry) => ContextNode`
- `get(id) => ContextNode`
- `chain(root) => ContextNode[]`
- `share(nodeIds, groupId) => ContextGroup`
- `groups(id) => GroupRef[]`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:write` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 链过长 | 分片并保留父子关系，不截断丢链 |
| 存储不可用 | 降级内存并**明确告知不持久** |
| 节点缺失 | 标记为断链而非静默跳过 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 上下文是**有序链**不是无序集合（回溯的基础）
- [ ] 编组共享一次给一组，不各自复制
- [ ] 父子关系完整
- [ ] 节点有版本
- [ ] 操作进日志埋点

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
