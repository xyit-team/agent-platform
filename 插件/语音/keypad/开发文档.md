# 插件 · 小键盘输入

| 项 | 值 |
|---|---|
| `id` | `keypad` |
| 所属分类 | 语音 |
| 风险级别 | safe（无风险） |
| 依赖插件 | 无 |
| 状态 | ⬜ 待开发 |

## 1. 目标

高频命令的高效输入方式，数字键绑定语义。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "keypad",
  version: "0.1.0",
  description: "高频命令的高效输入方式，数字键绑定语义。",
  capabilities: [/* 见 §4 */],
  permissions: ["device"],
  requires: [],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `show() => void`
- `hide() => void`
- `bindings() => Binding[]`
- `rebind(key, command) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `device` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 无可用按键位 | 隐藏面板并说明 |
| 冲突绑定 | 拒绝并指出冲突项 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 数字键可绑定语义命令
- [ ] 绑定可配置且持久化
- [ ] 冲突被拒绝而非静默覆盖
- [ ] 与文本输入可并存

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
