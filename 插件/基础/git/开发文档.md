# 插件 · 版本控制

| 项 | 值 |
|---|---|
| `id` | `git` |
| 所属分类 | 基础 |
| 风险级别 | elevated（需确认） |
| 依赖插件 | `fs` |
| 状态 | ⬜ 待开发 |

## 1. 目标

提供版本控制能力，支撑检查点、分支、回滚、审计。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "git",
  version: "0.1.0",
  description: "提供版本控制能力，支撑检查点、分支、回滚、审计。",
  capabilities: [/* 见 §4 */],
  permissions: ["fs:read", "fs:write", "process"],
  requires: ["fs"],
  riskLevel: "elevated",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `init() => VcsBinding`
- `commit(msg) => CommitRef`
- `branch(name) => string`
- `diff(a, b) => string`
- `revert(ref) => void`
- `log(n) => CommitRef[]`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:read` | 见目标所述用途 | 是 |
| `fs:write` | 见目标所述用途 | 是 |
| `process` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 无 git 环境 | 自动初始化（无→git 转化）并告知用户 |
| 有未提交改动 | 拒绝切分支并说明 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 无版本控制环境时自动初始化，保证检查点始终可用
- [ ] 切分支前检查未提交改动
- [ ] 回滚可逆且留痕
- [ ] 未提交改动不丢失

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
