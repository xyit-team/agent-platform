# 插件 · 文件读写

| 项 | 值 |
|---|---|
| `id` | `fs` |
| 所属分类 | 基础 |
| 风险级别 | safe（无风险） |
| 依赖插件 | 无 |
| 状态 | ⬜ 待开发 |

## 1. 目标

读写本地文件，Agent 一切文件操作的唯一入口。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "fs",
  version: "0.1.0",
  description: "读写本地文件，Agent 一切文件操作的唯一入口。",
  capabilities: [/* 见 §4 */],
  permissions: ["fs:read", "fs:write"],
  requires: [],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `read(path, encoding?) => FileContent`
- `write(path, content, opts?) => WriteResult`
- `list(path, glob?) => string[]`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:read` | 见目标所述用途 | 是 |
| `fs:write` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 路径越界 | 拒绝并说明范围 |
| 磁盘只读 | 写入失败并明确告知 |
| 文件被占用 | 重试后仍失败则报错 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

- [ ] 写入支持原子写
