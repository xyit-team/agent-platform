# 插件 · Word 读写

| 项 | 值 |
|---|---|
| `id` | `office-word` |
| 所属分类 | 文档办公 |
| 风险级别 | elevated（需确认） |
| 依赖插件 | 无 |
| 状态 | ⬜ 待开发 |

## 1. 目标

读写 Word 文档，屏蔽 COM 与 CLI 的差异。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "office-word",
  version: "0.1.0",
  description: "读写 Word 文档，屏蔽 COM 与 CLI 的差异。",
  capabilities: [/* 见 §4 */],
  permissions: ["process", "fs:read", "fs:write"],
  requires: [],
  riskLevel: "elevated",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `read(docRef, query?) => OfficeContent`
- `write(docRef, content, opts?) => WriteResult`
- `live.open(path) => LiveDoc`
- `live.close(h, save?) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `process` | 见目标所述用途 | 是 |
| `fs:read` | 见目标所述用途 | 是 |
| `fs:write` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 非 Windows | 只能 CLI 模式并明确告知不能操作活文档 |
| 文档被用户打开 | **拒绝写入**并提示 |
| 格式无法保真 | 明确列出降级项 |
| 保真失败 | 回滚 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] Windows 走 COM、非 Windows 走 CLI，ioSchema 一致
- [ ] 往返一次不丢常见格式
- [ ] 降级项明确列出
- [ ] 保真失败回滚
- [ ] 打开状态检测可靠

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
