# 插件 · LSP 代码智能

| 项 | 值 |
|---|---|
| `id` | `lsp` |
| 所属分类 | 文档办公 |
| 风险级别 | elevated（需确认） |
| 依赖插件 | 无 |
| 状态 | ⬜ 待开发 |

## 1. 目标

通过语言服务协议提供跳转、引用、诊断、重命名。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "lsp",
  version: "0.1.0",
  description: "通过语言服务协议提供跳转、引用、诊断、重命名。",
  capabilities: [/* 见 §4 */],
  permissions: ["process", "fs:read"],
  requires: [],
  riskLevel: "elevated",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `start(workspace, languageId) => LspSession`
- `definition(uri, pos) => Location[]`
- `references(uri, pos) => Location[]`
- `hover(uri, pos) => Hover`
- `diagnostics(uri) => Diagnostic[]`
- `rename(uri, pos, newName) => WorkspaceEdit`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `process` | 见目标所述用途 | 是 |
| `fs:read` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 语言服务器未安装 | 明确告知并建议安装 |
| 启动失败 | 用文本搜索替代并**明确告知精度下降** |
| 能力不支持 | 按 capabilities 逐项检测 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 跳转定义/查引用/查诊断可用
- [ ] 重命名前先展示引用
- [ ] capabilities 逐项检测

- [ ] 索引不外传
