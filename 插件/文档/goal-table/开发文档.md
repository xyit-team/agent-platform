# 插件 · 目标表

| 项 | 值 |
|---|---|
| `id` | `goal-table` |
| 所属分类 | 文档 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `doc-store` |
| 状态 | ⬜ 待开发 |

## 1. 目标

**目标表 = Agent 自查**。完成必须有证据。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "goal-table",
  version: "0.1.0",
  description: "**目标表 = Agent 自查**。完成必须有证据。",
  capabilities: [/* 见 §4 */],
  permissions: ["net", "fs:write"],
  requires: ["doc-store"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `upsert(goal) => Goal`
- `selfCheck(goalId) => CheckResult`
- `setEvidence(goalId, ref) => Goal`
- `blocked(goalId, reason) => Goal`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 见目标所述用途 | 是 |
| `fs:write` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 无法自查 | 明确标记未验证 |
| 证据缺失 | **不算完成** |
| 目标冲突 | 显式报出 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] **`evidence` 为空不算完成**
- [ ] 阻塞项自动进汇报第 3 段
- [ ] 自查结果带时间和检查人
- [ ] 是公文式汇报第 1/2/3 段的数据源

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
