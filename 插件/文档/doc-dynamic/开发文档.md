# 插件 · 动态文档

| 项 | 值 |
|---|---|
| `id` | `doc-dynamic` |
| 所属分类 | 文档 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `doc-store visual-render` |
| 状态 | ⬜ 待开发 |

## 1. 目标

文档随工作过程实时变化，多 Agent 产出可整合。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "doc-dynamic",
  version: "0.1.0",
  description: "文档随工作过程实时变化，多 Agent 产出可整合。",
  capabilities: [/* 见 §4 */],
  permissions: ["fs:write"],
  requires: ["doc-store visual-render"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `watch(docId) => DocUpdate[]`
- `integrate(docId, sources) => void`
- `sources(docId) => SourceRef[]`
- `render(docId) => View`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:write` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 多个 Agent 同时写 | 冲突显式报出 |
| 整合失败 | 保留原文档并说明 |
| 渲染不可用 | 降级纯文本 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 文档随工作过程实时更新
- [ ] **多 Agent 产出可整合进同一份**
- [ ] 每个贡献可追溯到 agentId
- [ ] 展示和编辑是同一对象

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
