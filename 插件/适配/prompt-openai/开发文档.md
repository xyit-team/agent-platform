# 插件 · OpenAI/GPT 家族

| 项 | 值 |
|---|---|
| `id` | `prompt-openai` |
| 所属分类 | 适配 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `prompt-family`、`adapter-ir`、`adapter-token` |
| 状态 | ⬜ 待开发 |

## 1. 目标

OpenAI 兼容系列。**注意：OpenAI 兼容的不都是 OpenAI 的** —— 缓存、推理块字段各家不同，别想当然。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。
核心已经持有 IR 定义、适配器接口和 passthrough 兜底 —— 裸核 + 任何端点都能跑。

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `adapt(canonical) => Raw`
- `tools(tools) => ToolSchema[]`
- `cache(prompt) => Setting`
- `reasoning(turn) => Raw`
- `supports(modelId) => boolean`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| — | **不申请任何权限** | — |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 推理字段名不认得 | 原样透传，**不丢也不猜** |
| 缓存策略不支持 | 明确告知本次未启用缓存 |
| 响应字段比预期少 | 按缺失处理，不填默认值 |
| 兼容但非 OpenAI | 按实际行为适配，**不照抄 OpenAI 假设** |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] **不假设「OpenAI 兼容 = OpenAI 行为」** —— 缓存和推理字段各家不同
- [ ] 推理字段不认得时透传不丢
- [ ] 缓存未启用时明确说明
- [ ] 字段缺失按缺失处理，不补默认值
- [ ] 适配是纯函数，有往返测试

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
