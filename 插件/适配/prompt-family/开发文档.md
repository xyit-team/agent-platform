# 插件 · 家族适配机制

| 项 | 值 |
|---|---|
| `id` | `prompt-family` |
| 所属分类 | 适配 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `prompt-compose` |
| 状态 | ⬜ 待开发 |

## 1. 目标

提示词适配的**注册与选择机制**。具体家族是各自独立的插件 —— 换家族要能独立装、独立关。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。
核心已经持有 IR 定义、适配器接口和 passthrough 兜底 —— 裸核 + 任何端点都能跑。

```ts
  capabilities: [/* 见 §4 */],

```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `register(adapter) => void`
- `select(modelId) => PromptAdapter`
- `describe(modelId) => AdapterInfo`
- `validate(adapter) => Validation`
- `list() => AdapterInfo[]`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| — | **不申请任何权限** | — |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 家族未适配 | 用 passthrough，**明确标注未适配** |
| 适配器加载失败 | 回落兜底，**记入埋点** |
| 版本超出钉定区间 | 该适配器主动拒绝 |
| 多个家族同时匹配 | 取最精确的 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 家族适配器**互相独立** —— 关掉 Claude 不影响 OpenAI
- [ ] 每个适配器钉定 model id 与版本区间
- [ ] 超出钉定版本主动拒绝而不是硬用
- [ ] 选择依据可查（为什么走了这套）
- [ ] 回落兜底时记入埋点

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
