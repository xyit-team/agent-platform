# 插件 · 提示词组装

| 项 | 值 |
|---|---|
| `id` | `prompt-compose` |
| 所属分类 | 适配 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `adapter-ir` |
| 状态 | ⬜ 待开发 |

## 1. 目标

把 提示规则 + 工具声明 + 记忆注入 + 上下文 拼成最终提示词。**顺序是契约的一部分，不是随便拼。**

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。
核心已经持有 IR 定义、适配器接口和 passthrough 兜底 —— 裸核 + 任何端点都能跑。

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `compose(parts) => Prompt`
- `order(parts) => Ordered`
- `inject(prompt, name, content) => Prompt`
- `strip(prompt, name) => Prompt`
- `budget() => number`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| — | **不申请任何权限** | — |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 组装超预算 | 按优先级裁剪并**明示裁了什么** |
| 片段缺失 | 用兜底并告警，不静默留空 |
| 注入占位符无内容 | 标为已注入空，并说明原因 |
| 顺序冲突 | 按契约的优先级，不按加入顺序 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] **组装顺序是显式契约**，改顺序要有测试
- [ ] 裁剪时明示丢了哪些片段
- [ ] 每个占位符可单独关闭
- [ ] 组装是纯函数，可单测
- [ ] 注入内容可追溯来源

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
