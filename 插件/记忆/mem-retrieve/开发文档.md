# 插件 · 检索后处理管线

| 项 | 值 |
|---|---|
| `id` | `mem-retrieve` |
| 所属分类 | 记忆 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `mem-taggraph`、`mem-coldbase` |
| 状态 | ⬜ 待开发 |

## 1. 目标

检索结果的后处理链：**TimeDecay → Rerank → Associate → 排序与预算裁剪**。任一级不可用就跳过该级并记入埋点。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

```ts
  capabilities: [/* 见 §4 */],

```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `decay(candidates, now) => Scored[]`
- `rerank(query, candidates) => Scored[]`
- `associate(seed, candidates) => Scored[]`
- `finalize(scored, budget) => Scored[]`
- `stages() => Stage[]`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:read` | 读文件与已有数据 | 是 |
| `net` | 调用模型与外部服务 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 某级不可用 | 跳过该级并**记入埋点** |
| 管线超时 | 直接返回 top-k，标注未完成 |
| 重排模型不可用 | 退化为时间序 |
| 联想未启用 | 明确说明走了哪几级 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 四级是**可独立开关**的，不是硬编码
- [ ] 跳过的级要记入埋点，不静默
- [ ] 时间衰减：越久越靠后，但不归零
- [ ] 重排模型可换（本地/云端）
- [ ] 最终裁剪按预算，不是按拍脑袋

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
