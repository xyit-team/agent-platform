# 插件 · 窗口记忆管理

| 项 | 值 |
|---|---|
| `id` | `mem-window` |
| 所属分类 | 记忆 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `doc-store`、`time-rewind` |
| 状态 | ⬜ 待开发 |

## 1. 目标

窗口内的记忆管理：显著性标记、压缩触发点、窗口记忆持久化。**消息本身由核心的对话循环持有**，本插件管的是怎么管。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

```ts
  capabilities: [/* 见 §4 */],

```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `mark(messageId, salience) => void`
- `salience(messageId) => number`
- `compactPoint(planId) => MessageId`
- `persist(sessionId) => Ref`
- `restore(ref) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:read` | 读文件与已有数据 | 是 |
| `fs:write` | 写文件与落盘 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 超上下文 | 按显著性压缩，**不静默截断** |
| 压缩丢失关键信息 | 宁可留长，**明确告警** |
| 持久化失败 | 保留内存态，报告未落盘 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 压缩是显式决策，有压缩点记录
- [ ] 被压缩的内容可回溯
- [ ] 不静默截断对话
- [ ] 窗口记忆可交接给下一个窗口

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
