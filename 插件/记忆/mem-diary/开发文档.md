# 插件 · 热记忆日记

| 项 | 值 |
|---|---|
| `id` | `mem-diary` |
| 所属分类 | 记忆 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `mem-extract`、`mem-taggraph` |
| 状态 | ⬜ 待开发 |

## 1. 目标

经历、关系、反思。这是**热的** —— 高频被检索、自动注入。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "mem-diary",
  version: "0.1.0",
  description: "经历、关系、反思。这是**热的** —— 高频被检索、自动注入。",
  capabilities: [/* 见 §4 */],
  permissions: ["fs:write", "net"],
  requires: ["mem-extract", "mem-taggraph"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `write(entry) => Entry`
- `read(query) => Entry[]`
- `byEntity(entity) => Entry[]`
- `byEmotion(tag) => Entry[]`
- `link(entryId, entityId) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:write` | 写文件与落盘 | 是 |
| `net` | 调用模型与外部服务 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 写入失败 | 不丢，暂存并重试 |
| 涉及他人敏感信息 | 脱敏后再落，**标明已脱敏** |
| 检索不到 | 明确无结果 |
| 日志过长 | 归档旧日记，保留索引 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 日记是热的，会被自动注入
- [ ] 他人信息落笔前脱敏
- [ ] 每条可回溯到来源对话
- [ ] 用户可查看编辑删除
- [ ] 不因检索失败而静默丢弃

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
