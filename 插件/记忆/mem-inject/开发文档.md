# 插件 · RAG 占位符注入

| 项 | 值 |
|---|---|
| `id` | `mem-inject` |
| 所属分类 | 记忆 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `mem-prefetch`、`mem-retrieve` |
| 状态 | ⬜ 待开发 |

## 1. 目标

在提示词里预留 `{{日记本}}` 这类占位符，生成前拦截请求，把检索结果替换进去。**预算超了要明示截断。**

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

```ts
import type { PluginManifest } from "@core/types";

  capabilities: [/* 见 §4 */],
  permissions: ["fs:read"],
  requires: ["mem-prefetch", "mem-retrieve"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },

```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `register(name, source) => void`
- `intercept(request) => Request`
- `replace(name, content) => Request`
- `budget() => number`
- `truncated(name) => boolean`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:read` | 读文件与已有数据 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 超出预算 | 按分数截断并**明示已截断** |
| 占位符无结果 | 替换为空并说明为什么空 |
| 检索超时 | 用上一轮结果并标注陈旧 |
| 占位符拼错 | 忽略并报出，不静默跳过 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 占位符是**显式声明**的，不是隐式魔法
- [ ] 截断必须明示，不能悄悄少给
- [ ] 注入内容标明来自哪次检索
- [ ] 注入前经过过滤（未确认敏感信息不进）
- [ ] 每个占位符可单独关闭

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
