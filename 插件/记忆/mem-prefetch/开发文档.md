# 插件 · 主动预取

| 项 | 值 |
|---|---|
| `id` | `mem-prefetch` |
| 所属分类 | 记忆 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `mem-taggraph`、`mem-profile`、`mem-diary` |
| 状态 | ⬜ 待开发 |

## 1. 目标

每轮对话背后实时计算"**此时此刻应该知道什么**"。不需要用户主动检索 —— 记忆像引力一样主动流过来。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "mem-prefetch",
  version: "0.1.0",
  description: "每轮对话背后实时计算\"**此时此刻应该知道什么**\"。不需要用户主动检索 —— 记忆像引力一样主动流过来。",
  capabilities: [/* 见 §4 */],
  permissions: ["net", "fs:read"],
  requires: ["mem-taggraph", "mem-profile", "mem-diary"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `prefetch(turn) => MemoRef[]`
- `score(turn, memo) => number`
- `budget() => TokenBudget`
- `why(memoId) => Reason`
- `cancel(turnId) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 调用模型与外部服务 | 是 |
| `fs:read` | 读文件与已有数据 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 预算不足 | 只取高分，**明确说明取了几个、丢了几个** |
| 预取超时 | **不阻塞主对话** |
| 无相关记忆 | 安静返回空，不硬凑 |
| 联想过头 | 按分数截断 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] **每轮都算，不等用户检索**
- [ ] 无关键词匹配时也能浮现（走联想）
- [ ] 预取不阻塞主对话
- [ ] 结果可解释（说得出为什么想起它）
- [ ] 预取内容在预算内

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
