# 插件 · VCPTimeLine

| 项 | 值 |
|---|---|
| `id` | `mem-timeline` |
| 所属分类 | 记忆 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `mem-consolidate`、`doc-store`、`mem-onering` |
| 状态 | ⬜ 待开发 |

## 1. 目标

长期阶段概览：按月归纳，数年级的记忆骨架。回答"我现在处在什么阶段"。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

  capabilities: [/* 见 §4 */],
  permissions: ["fs:read", "fs:write"],
  requires: ["mem-consolidate", "doc-store", "mem-onering"],

  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `append(eventId, range) => void`
- `readByRange(range) => Stage[]`
- `byPhase(phaseId) => Stage[]`
- `currentStage() => Stage`
- `diff(a, b) => Change[]`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:read` | 读文件与已有数据 | 是 |
| `fs:write` | 写文件与落盘 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 无阶段数据 | 只按月组织，**明确说明粒度更粗** |
| 归纳未完成 | 用上次骨架，标注时间 |
| 数据缺失 | 跳过该月，保留缺口标记 |
| 时间倒流 | 不覆盖已有阶段 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 能回答"我现在在哪个阶段"
- [ ] 阶段变更留时间戳
- [ ] 数据缺失显式标记，不填补
- [ ] 骨架可回溯到事件线
- [ ] 换窗口不影响骨架

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
