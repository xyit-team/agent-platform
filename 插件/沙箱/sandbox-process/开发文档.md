# 插件 · 进程级沙箱

| 项 | 值 |
|---|---|
| `id` | `sandbox-process` |
| 所属分类 | 沙箱 |
| 风险级别 | safe（无风险） |
| 依赖插件 | 无 |
| 状态 | ⬜ 待开发 |

## 1. 目标

以独立进程隔离执行，限制挂载、网络和资源。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "sandbox-process",
  version: "0.1.0",
  description: "以独立进程隔离执行，限制挂载、网络和资源。",
  capabilities: [/* 见 §4 */],
  permissions: ["process"],
  requires: [],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `create(spec) => SandboxHandle`
- `exec(handle, cmd) => ExecResult`
- `destroy(handle) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `process` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 资源超限 | 终止子进程并报告 |
| 挂载越界 | 拒绝启动 |
| 子进程逃逸尝试 | 记录并终止 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 默认禁网
- [ ] 只读挂载确实不可写
- [ ] 资源上限强制生效
- [ ] 子进程崩溃不影响宿主
- [ ] 销毁后无残留进程

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
