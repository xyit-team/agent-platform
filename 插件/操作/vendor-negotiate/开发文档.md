# 插件 · 商家沟通议价

| 项 | 值 |
|---|---|
| `id` | `vendor-negotiate` |
| 所属分类 | 操作 |
| 风险级别 | privileged（每次确认） |
| 依赖插件 | `action-authorize`、`mail-send` |
| 状态 | ⬜ 待开发 |

## 1. 目标

代表用户与商家沟通、议价。**对外发言**，超出授权范围必须回到用户。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {

  capabilities: [/* 见 §4 */],
  permissions: ["net"],
  requires: ["action-authorize", "mail-send"],
  riskLevel: "privileged",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `draft(goal, constraints) => Message`
- `negotiate(threadId, message) => Thread`
- `accept(threadId, offerId) => Deal`
- `reject(threadId, reason) => void`
- `escalate(threadId) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 调用模型与外部服务 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 超出授权额度 | **必须回到用户**，不自行加码 |
| 商家回复歧义 | 不猜，停下询问 |
| 对话超时 | 保存线程，**明确告知停在第几轮** |
| 身份表述不清 | 不冒充用户措辞，明确说明是代为沟通 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] **超出授权额度立刻回到用户**
- [ ] 对外发言前可预览措辞
- [ ] 不以用户身份编造用户没说过的话
- [ ] 每轮发言进审计，标明代为沟通
- [ ] 接受前展示最终条款

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
