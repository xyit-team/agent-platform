# 插件 · 预订

| 项 | 值 |
|---|---|
| `id` | `booking` |
| 所属分类 | 操作 |
| 风险级别 | privileged（每次确认） |
| 依赖插件 | `action-authorize`、`web-search`、`purchase` |
| 状态 | ⬜ 待开发 |

## 1. 目标

预订机票、酒店、餐厅。**产生不可逆承诺和花费**。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "booking",
  version: "0.1.0",
  description: "预订机票、酒店、餐厅。**产生不可逆承诺和花费**。",
  capabilities: [/* 见 §4 */],
  permissions: ["net", "fs:read"],
  requires: ["action-authorize", "web-search", "purchase"],
  riskLevel: "privileged",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `search(request) => Offer[]`
- `quote(offerId) => Quote`
- `book(offerId) => Booking`
- `cancel(bookingId) => CancelResult`
- `status(bookingId) => Status`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 调用模型与外部服务 | 是 |
| `fs:read` | 读文件与已有数据 | 否 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 授权缺失 | **只到报价为止，不下单** |
| 支付失败 | **不重试**，报告失败 |
| 库存变化 | 重新报价并要求重新确认 |
| 政策不明 | 问清再订，不猜退改规则 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] **没逐次授权不产生任何不可逆承诺**
- [ ] 退改规则在确认时一并展示
- [ ] 支付失败不自动重试
- [ ] 预订记录可查可取消
