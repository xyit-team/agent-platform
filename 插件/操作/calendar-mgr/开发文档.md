# 插件 · 日历提醒

| 项 | 值 |
|---|---|
| `id` | `calendar-mgr` |
| 所属分类 | 操作 |
| 风险级别 | elevated（需确认） |
| 依赖插件 | `action-authorize` |
| 状态 | ⬜ 待开发 |

## 1. 目标

读日历、建事件、设提醒。冲突显式报出。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "calendar-mgr",
  version: "0.1.0",
  description: "读日历、建事件、设提醒。冲突显式报出。",
  capabilities: [/* 见 §4 */],
  permissions: ["net"],
  requires: ["action-authorize"],
  riskLevel: "elevated",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `list(range) => Event[]`
- `create(event) => Event`
- `update(eventId, patch) => Event`
- `remove(eventId) => void`
- `remind(eventId, at) => Reminder`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 调用模型与外部服务 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 时段冲突 | 显式报冲突，不静默覆盖已有日程 |
| 无日历账号 | 只存本地，**明确告知未同步** |
| 同步失败 | 保留本地版本并报告 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 冲突显式报出，不静默覆盖
- [ ] 读取他人日历需单独授权
- [ ] 未同步状态要明示
- [ ] 删除操作可撤销（软删）

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
