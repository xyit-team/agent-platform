# 插件 · 网页正文抓取

| 项 | 值 |
|---|---|
| `id` | `web-read` |
| 所属分类 | 操作 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `web-search`、`doc-store` |
| 状态 | ⬜ 待开发 |

## 1. 目标

抓取并清洗网页正文，保留出处。抓不到就保留链接，不猜内容。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "web-read",
  version: "0.1.0",
  description: "抓取并清洗网页正文，保留出处。抓不到就保留链接，不猜内容。",
  capabilities: [/* 见 §4 */],
  permissions: ["net", "fs:write"],
  requires: ["web-search", "doc-store"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `fetch(url) => Page`
- `extract(page, selector) => Text`
- `cite(text) => Citation`
- `traverse(url, depth) => Page[]`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 调用模型与外部服务 | 是 |
| `fs:write` | 写文件与落盘 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 付费墙/登录墙 | 明确告知需用户处理，**不绕过** |
| 抓取失败 | 保留链接，不猜测内容 |
| 正文提取为空 | 回退到原文链接并标注 |
| robots 禁止 | 不抓 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 每段正文可回溯到具体 URL
- [ ] 付费墙和登录墙不绕过
- [ ] 抓不到就说抓不到，不填充模型记忆
- [ ] 抓取范围受授权约束

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
