# 插件 · 云端文档

| 项 | 值 |
|---|---|
| `id` | `doc-create` |
| 所属分类 | 操作 |
| 风险级别 | elevated（需确认） |
| 依赖插件 | `action-authorize`、`doc-store` |
| 状态 | ⬜ 待开发 |

## 1. 目标

在云端文档服务创建和编辑文档。没账号就存本地，不假装同步了。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "doc-create",
  version: "0.1.0",
  description: "在云端文档服务创建和编辑文档。没账号就存本地，不假装同步了。",
  capabilities: [/* 见 §4 */],
  permissions: ["net"],
  requires: ["action-authorize", "doc-store"],
  riskLevel: "elevated",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `create(title, body) => DocRef`
- `append(docRef, body) => DocRef`
- `update(docRef, patch) => DocRef`
- `share(docRef, acl) => DocRef`
- `read(docRef) => Doc`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 调用模型与外部服务 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 无服务账号 | 存本地 md，**明确告知未上云** |
| 权限不足 | 明确告知，不换账号重试 |
| 共享失败 | 保留本地版本并报告 |
| 服务不可用 | 本地编辑 + 稍后同步 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 无账号时明确区分本地与云端
- [ ] 共享要显示接收方再执行
- [ ] 失败保留本地版本
- [ ] 本地与云端冲突要报出，不静默覆盖

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
