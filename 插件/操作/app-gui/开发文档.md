# 插件 · 桌面应用操作

| 项 | 值 |
|---|---|
| `id` | `app-gui` |
| 所属分类 | 操作 |
| 风险级别 | elevated（需确认） |
| 依赖插件 | `computer-use`、`action-authorize`、`screen-capture` |
| 状态 | ⬜ 待开发 |

## 1. 目标

操作原生桌面应用（非浏览器）：邮件客户端、日历、Office 等。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "app-gui",
  version: "0.1.0",
  description: "操作原生桌面应用（非浏览器）：邮件客户端、日历、Office 等。",
  capabilities: [/* 见 §4 */],
  permissions: ["device"],
  requires: ["computer-use", "action-authorize", "screen-capture"],
  riskLevel: "elevated",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `launch(appId) => Window`
- `focus(window) => void`
- `act(window, action) => void`
- `read(window, target) => string`
- `windows() => Window[]`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `device` | 控制鼠标键盘屏幕 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 应用不存在 | 明确告知，不装也不替代 |
| 无障碍接口不可用 | 降级为屏幕坐标操作，**明确告知精度下降** |
| 应用弹窗打断 | 停止并报告 |
| 操作到一半应用崩溃 | 停止，**明确告知完成到哪一步** |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 原生应用与浏览器分开，不混用一套定位
- [ ] 无障碍接口不可用时明确告知精度下降
- [ ] 操作中断要说明完成到哪一步，不假装做完
- [ ] 不代替用户在应用内做无授权的动作

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
