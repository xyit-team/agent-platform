# 插件 · 在线购买

| 项 | 值 |
|---|---|
| `id` | `purchase` |
| 所属分类 | 操作 |
| 风险级别 | privileged（每次确认） |
| 依赖插件 | `action-authorize`、`browser-act` |
| 状态 | ⬜ 待开发 |

## 1. 目标

完成在线购买。**花钱**。支付前必须逐次确认。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "purchase",
  version: "0.1.0",
  description: "完成在线购买。**花钱**。支付前必须逐次确认。",
  capabilities: [/* 见 §4 */],
  permissions: ["net", "fs:read"],
  requires: ["action-authorize", "browser-act"],
  riskLevel: "privileged",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `cart(items) => Cart`
- `checkout(cartId) => CheckoutPage`
- `pay(checkoutId, authId) => Receipt`
- `track(orderId) => Order`
- `abort(checkoutId) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 调用模型与外部服务 | 是 |
| `fs:read` | 读文件与已有数据 | 否 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| **无逐次授权不支付** —— 这是硬约束，不可配置降级 | **明确告知不可用** |
| 支付页信息不全 | 停下询问，不猜 |
| 支付失败 | **不重试**，报告失败 |
| 金额超限 | 直接拒绝并报出上限 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] **没有逐次授权绝不支付**
- [ ] 支付前展示完整订单（商品、金额、收款方）
- [ ] 支付失败不重试
- [ ] 支付动作可审计（金额、时间、授权来源）
- [ ] 不会替用户做"看起来划算"的判断

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
