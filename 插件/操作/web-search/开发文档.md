# 插件 · 搜索

| 项 | 值 |
|---|---|
| `id` | `web-search` |
| 所属分类 | 操作 |
| 风险级别 | safe（无风险） |
| 依赖插件 | —（仅依赖核心） |
| 状态 | ⬜ 待开发 |

## 1. 目标

联网搜索，返回带来源的结果。结果不足就标明不足，不编。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "web-search",
  version: "0.1.0",
  description: "联网搜索，返回带来源的结果。结果不足就标明不足，不编。",
  capabilities: [/* 见 §4 */],
  permissions: ["net"],
  requires: [],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `search(query, opts) => Result[]`
- `news(query, opts) => Result[]`
- `suggest(query) => string[]`
- `sources() => Source[]`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 调用模型与外部服务 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 无搜索源 | 明确告知，不返回空列表假装没有 |
| 结果不足 | 标明不足，**不编造来源** |
| 超时 | 返回部分结果并标注截断 |
| 源被墙 | 换源并说明换了哪个 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 每条结果带出处和抓取时间
- [ ] 结果不足时明确说不足
- [ ] 不返回无出处的结论
- [ ] 搜索词原样记录，便于复现

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
