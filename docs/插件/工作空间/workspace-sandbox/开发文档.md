# 插件 · 沙箱工作空间

| 项 | 值 |
|---|---|
| `id` | `workspace-sandbox` |
| 所属分类 | 工作空间 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `sandbox-mgr` |
| 状态 | ⬜ 待开发 |

## 1. 目标

用沙箱为任务创建隔离空间，隔离更强。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "workspace-sandbox",
  version: "0.1.0",
  description: "用沙箱为任务创建隔离空间，隔离更强。",
  capabilities: [/* 见 §4 */],
  permissions: ["process"],
  requires: ["sandbox-mgr"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `create(spec) => WorkspaceHandle`
- `exec(handle, cmd) => ExecResult`
- `commitAndExit(handle, how) => ArtifactRef`
- `discard(handle) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `process` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 沙箱不可用 | 降级到 git 工作空间并**明确告知隔离强度下降** |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 任务在沙箱内完成不落宿主
- [ ] 退出时制品可导出
- [ ] 沙箱销毁彻底无残留
- [ ] 降级路径有记录

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
