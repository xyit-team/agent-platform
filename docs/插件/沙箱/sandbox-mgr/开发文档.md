# 插件 · 沙箱生命周期与降级决策

| 项 | 值 |
|---|---|
| `id` | `sandbox-mgr` |
| 所属分类 | 沙箱 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `sandbox-container sandbox-process` |
| 状态 | ⬜ 待开发 |

## 1. 目标

决定用哪种沙箱、按什么顺序降级。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "sandbox-mgr",
  version: "0.1.0",
  description: "决定用哪种沙箱、按什么顺序降级。",
  capabilities: [/* 见 §4 */],
  permissions: [],
  requires: ["sandbox-container sandbox-process"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `acquire(spec) => SandboxHandle`
- `release(handle) => void`
- `currentLevel() => "container"|"process"|"none"`
- `onDegrade(cb) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| — | 不需要权限 | — |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 容器不可用 | 降级进程→降级宿主，**每次降级都记入日志埋点并通知用户** |
| — | pentest 类工具在无隔离时**拒绝运行，不降级** |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 降级链固定且可观测
- [ ] 每次降级都留痕
- [ ] pentest 在无隔离时拒绝执行
- [ ] 沙箱资源可回收
- [ ] 选择理由可查

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
