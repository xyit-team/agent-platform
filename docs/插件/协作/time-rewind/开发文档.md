# 插件 · 时间回溯与分支

| 项 | 值 |
|---|---|
| `id` | `time-rewind` |
| 所属分类 | 协作 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `workspace-git context-chain` |
| 状态 | ⬜ 待开发 |

## 1. 目标

回到某个决策点重新分叉，**不是撤销**。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "time-rewind",
  version: "0.1.0",
  description: "回到某个决策点重新分叉，**不是撤销**。",
  capabilities: [/* 见 §4 */],
  permissions: ["fs:write"],
  requires: ["workspace-git context-chain"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `checkpoint(note) => DecisionPoint`
- `rewindTo(pointId, reason) => Branch`
- `listBranches(from) => Branch[]`
- `adopt(branchId) => void`
- `discard(branchId) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:write` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 无可回溯点 | 明确说明不支持回溯 |
| 分支跑坏 | 不影响主干，标失败并保留其他分支 |
| 工作区冲突 | 换名并说明 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 可从任意决策点回溯
- [ ] **回溯是分叉不是撤销**
- [ ] 每个分支独立工作区互不污染
- [ ] 主干和分支都可被采纳
- [ ] 回溯理由必须记录

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
