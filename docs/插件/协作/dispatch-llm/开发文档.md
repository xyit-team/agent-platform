# 插件 · LLM 级任务分发

| 项 | 值 |
|---|---|
| `id` | `dispatch-llm` |
| 所属分类 | 协作 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `context-chain` |
| 状态 | ⬜ 待开发 |

## 1. 目标

由模型判断任务粒度和分法，输出可质疑的理由。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "dispatch-llm",
  version: "0.1.0",
  description: "由模型判断任务粒度和分法，输出可质疑的理由。",
  capabilities: [/* 见 §4 */],
  permissions: ["net"],
  requires: ["context-chain"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `assess(task, ctx) => DispatchDecision`
- `explain(decisionId) => string`
- `override(decisionId, decision) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 模型不可用 | 退化为固定规则并**明确告知已降级** |
| 分发结果不合理 | 用户可质疑并覆盖 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 策略由模型判断（single/parallel/debate/hierarchical）
- [ ] **必须输出 rationale**
- [ ] 用户可质疑和覆盖
- [ ] 分发决策进日志埋点

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
