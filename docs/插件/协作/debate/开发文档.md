# 插件 · 取一测试

| 项 | 值 |
|---|---|
| `id` | `debate` |
| 所属分类 | 协作 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `agent-pool context-chain` |
| 状态 | ⬜ 待开发 |

## 1. 目标

独立作答 → 互相争论 → 取一，保留少数意见。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "debate",
  version: "0.1.0",
  description: "独立作答 → 互相争论 → 取一，保留少数意见。",
  capabilities: [/* 见 §4 */],
  permissions: ["net"],
  requires: ["agent-pool context-chain"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `run(unit, agents) => DebateSession`
- `critique(sessionId, from, to) => Critique[]`
- `decide(sessionId) => Decision`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 智能体不足 2 个 | 退化为 single 并说明 |
| 争论超轮次上限 | 停止并保留当前最优，**告知用户已达上限** |
| 意见一致 | 仍记录结论但标注无争议 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收
