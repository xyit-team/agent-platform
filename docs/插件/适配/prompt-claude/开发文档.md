# 插件 · Claude 家族

| 项 | 值 |
|---|---|
| `id` | `prompt-claude` |
| 所属分类 | 适配 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `prompt-family`、`adapter-ir`、`adapter-token` |
| 状态 | ⬜ 待开发 |

## 1. 目标

Claude 系列的提示词与工具调用约定。**版本钉定** —— 约定随模型版本变，不钉住会静默降级。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。
核心已经持有 IR 定义、适配器接口和 passthrough 兜底 —— 裸核 + 任何端点都能跑。

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `adapt(canonical) => Raw`
- `tools(tools) => ToolSchema[]`
- `cache(prompt) => Breakpoint[]`
- `thinking(turn) => Raw`
- `supports(modelId) => boolean`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| — | **不申请任何权限** | — |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 超出钉定版本 | **降级到 passthrough 并记入埋点** |
| 推理块格式不认得 | 原样透传，**绝不丢** |
| 缓存断点放不下 | 放弃缓存，**明确告知这次没缓存** |
| 工具 schema 不支持 | 报出不支持的能力 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收
