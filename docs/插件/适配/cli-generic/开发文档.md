# 插件 · 通用 CLI 接法

| 项 | 值 |
|---|---|
| `id` | `cli-generic` |
| 所属分类 | 适配 |
| 风险级别 | elevated（需确认） |
| 依赖插件 | `cli-bridge` |
| 状态 | ⬜ 待开发 |

## 1. 目标

其他 agent CLI 的**声明式**接法。命令行差异是**数据**，不是逻辑。

**每接一家 CLI，必须同时声明它的配置隔离口** —— 不然就走不了中转。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。
核心已经持有 IR 定义、适配器接口和 passthrough 兜底 —— 裸核 + 任何端点都能跑。

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `define(spec) => CliSpec`
- `build(spec, args) => CliArgs`
- `parse(spec, stdout) => CliResult`     // 全量，不截断
- `resume(spec, sessionId) => CliArgs`   // CLI 会话重建
- `accepts(spec, account) => boolean`
```

```ts
interface CliSpec {
  id: string;
  bin: string;
  build: { promptFlag: string; resumeFlag?: string; jsonFlag?: string };
  parse: (stdout: string) => CliResult;
  /** 方式 A 用的口：把配置目录指到我们造的那份。没有就留空 */
  configDirEnv?: string;          // 如 "CODEX_HOME" / "GEMINI_HOME"
  /** token 走哪个环境变量 */
  tokenEnv?: string;
  /** 方式 B：是否允许改用户真配置。默认 false；CLI 会话下一律不采纳 true */
  allowFilePatch: boolean;
  /** 空闲多久自退。0 = 永不（不推荐） */
  idleTimeoutMs?: number;
}
```

**`configDirEnv` 和 `allowFilePatch` 声明不出来 = 该 CLI 走不了中转账号** —— 这两个字段是 `cli-profile` 决定走 A 还是 B、**以及 `detect()` 去哪读现状**的唯一依据。声明要如实，留空蒙混过关等于让 `detect()` 永远返回 `absent`，然后每次都重写配置。

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `process` | 执行本地命令 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 声明缺字段 | 拒绝装载，**不猜** |
| 解析结果不可信 | **保留全量原文**并标明，不截断 |
| CLI 行为与声明不符 | 明确告警 |
| 超时 | 与 cli-bridge 一致，报告已完成部分 |
| `configDirEnv` 缺失且 `allowFilePatch` 为 false | **拒绝该账号走 CLI**，回落 API 并说明 |
| 声明的隔离口在该版本失效 | 明确告警，**不自动降级到改真配置** |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] **声明缺字段直接拒绝，不猜**
- [ ] 每家 CLI 都声明了 `configDirEnv` / `allowFilePatch`，`cli-profile` 据此决定 A 还是 B、以及 `detect()` 去哪读
- [ ] 两者都缺时**明确告知该 CLI 走不了中转账号**，不静默改用户配置
- [ ] `CliSpec` 与 [../../../开发文档/12-TypeScript接口契约.md](../../../开发文档/12-TypeScript接口契约.md) §1.3.1 一致
- [ ] 声明 `resumeFlag` 的 CLI 能重建 CLI 会话
- [ ] 声明是数据，可以审阅
- [ ] 解析失败保留全量原文
- [ ] 实际行为与声明不符要能发现
- [ ] 不把逻辑写死在适配器里

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
