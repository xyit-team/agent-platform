# 插件 · 错误归一与重试

| 项 | 值 |
|---|---|
| `id` | `adapter-error` |
| 所属分类 | 适配 |
| 风险级别 | safe（无风险） |
| 依赖插件 | —（仅依赖核心） |
| 状态 | ⬜ 待开发 |

## 1. 目标

错误码、限流、超时归一。**重试策略要按家区分** —— 有的家重试会重复计费。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。
核心已经持有 IR 定义、适配器接口和 passthrough 兜底 —— 裸核 + 任何端点都能跑。

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `toIR(raw) => Canonical`
- `classify(err) => ErrorKind`
- `retryable(kind) => boolean`
- `retry(policy) => Attempt`
- `backoff(attempt) => Duration`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 未知错误 | 按**不可重试**处理并报出 |
| 连续失败 | 熔断，不无限重试 |
| 重试会重复计费的动作 | 不重试，报告失败 |
| 限流 | 按各家返回的等待时间退避，不自己猜 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 未知错误默认不可重试（宁可少试不错试）
- [ ] 退避时间优先用服务端返回的值
- [ ] 熔断生效后明确报出
- [ ] 错误信息保留原始状态码，便于排查
- [ ] 重试次数有上限且进埋点

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
