# 插件 · 流式事件归一

| 项 | 值 |
|---|---|
| `id` | `adapter-stream` |
| 所属分类 | 适配 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `adapter-ir` |
| 状态 | ⬜ 待开发 |

## 1. 目标

各家流式事件的形态不同（字段名、增量合并方式、结束标记），统一成一种事件流。**中断不等于正常结束。**

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。
核心已经持有 IR 定义、适配器接口和 passthrough 兜底 —— 裸核 + 任何端点都能跑。

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `toIR(raw) => Event`
- `fromIR(event) => RawChunk`
- `merge(partials) => Delta`
- `done() => boolean`
- `abort() => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| — | **不申请任何权限** | — |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 流中断 | 标为**不完整**，不假装正常结束 |
| 事件缺失 | 回退到非流式，**明确告知已回退** |
| 增量合并失败 | 按原文拼接，**明确告知质量下降** |
| 结束标记未到 | 超时收尾，标明未收到结束标记 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 中断被标为不完整，**不当成正常结束**
- [ ] 各家结束标记都能识别
- [ ] 增量合并（含分块切断的多字节字符）正确
- [ ] 回退到非流式时明示
- [ ] abort 能真正终止上游连接

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
