# 插件 · 规范化中间表示

| 项 | 值 |
|---|---|
| `id` | `adapter-ir` |
| 所属分类 | 适配 |
| 风险级别 | safe（无风险） |
| 依赖插件 | —（仅依赖核心） |
| 状态 | ⬜ 待开发 |

## 1. 目标

内外两套格式之间**唯一**的中间表示。适配只做一次，两边都适配它 —— 不做这层，散落的对接会变成 N×M。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。
核心已经持有 IR 定义、适配器接口和 passthrough 兜底 —— 裸核 + 任何端点都能跑。

```ts
import type { PluginManifest } from "@core/types";

  capabilities: [/* 见 §4 */],

```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `toIR(raw, modelId) => Canonical`
- `fromIR(canonical, modelId) => Raw`
- `validate(canonical) => Validation`
- `version() => string`
- `diff(a, b) => Field[]`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| — | **不申请任何权限** | — |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| IR 版本不匹配 | 按最新版本解析，**记入埋点** |
| 未知字段 | 保留原样透传，**不丢数据** |
| 转换失败 | 拒绝该轮，不产出半成品 IR |
| 字段类型冲突 | 报出冲突，不静默强转 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] IR 覆盖消息/工具/多模态/推理块/缓存标记全部形态
- [ ] **未知字段透传不丢** —— 这是适配器不吞信息的保证
- [ ] IR 转换是纯函数，无 IO，可单测
- [ ] 版本可查，跨版本转换有测试覆盖
- [ ] 往返转换（有损字段要标出来）

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
