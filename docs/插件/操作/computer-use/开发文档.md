# 插件 · 屏幕控制

| 项 | 值 |
|---|---|
| `id` | `computer-use` |
| 所属分类 | 操作 |
| 风险级别 | elevated（需确认） |
| 依赖插件 | `screen-capture` |
| 状态 | ⬜ 待开发 |

## 1. 目标

鼠标键盘的通用控制：点击、输入、滚动、拖拽。看用 screen-capture，做用本插件。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "computer-use",
  version: "0.1.0",
  description: "鼠标键盘的通用控制：点击、输入、滚动、拖拽。看用 screen-capture，做用本插件。",
  capabilities: [/* 见 §4 */],
  permissions: ["device"],
  requires: ["screen-capture"],
  riskLevel: "elevated",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `move(x, y) => void`
- `click(target, button) => void`
- `type(text) => void`
- `scroll(dx, dy) => void`
- `drag(from, to) => void`
- `key(combo) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `device` | 控制鼠标键盘屏幕 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 无辅助功能权限 | **拒绝执行**，不降级为盲操作 |
| 目标窗口丢失 | 停止并报告，不继续点 |
| 分辨率/缩放变化 | 重新取坐标，**明确告知坐标已重算** |
| 操作超时 | 停止，保留现场供检查 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 每次操作前确认目标窗口，不盲点
- [ ] 坐标基于当前缩放，换分辨率后重取
- [ ] 无权限直接拒绝，不做降级盲操作
- [ ] 操作序列可回放（进埋点）

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
