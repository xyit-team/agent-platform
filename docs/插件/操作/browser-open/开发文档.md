# 插件 · 浏览器会话

| 项 | 值 |
|---|---|
| `id` | `browser-open` |
| 所属分类 | 操作 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `computer-use` |
| 状态 | ⬜ 待开发 |

## 1. 目标

打开浏览器、管理标签页与浏览器会话。浏览器会话是有状态的，所以它独立成一个插件。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "browser-open",
  version: "0.1.0",
  description: "打开浏览器、管理标签页与浏览器会话。浏览器会话是有状态的，所以它独立成一个插件。",
  capabilities: [/* 见 §4 */],
  permissions: ["device"],
  requires: ["computer-use"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `open(url) => Tab`
- `newTab(url) => Tab`
- `switchTab(tabId) => void`
- `close(tabId) => void`
- `session() => Session`
- `restore(sessionId) => Session`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `device` | 控制鼠标键盘屏幕 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 浏览器不可用 | 明确告知，不静默改用其他方式 |
| 浏览器会话丢失 | 重新建立并**明确告知登录态没了** |
| 多实例冲突 | 列出让用户选，不抢窗口 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 登录态属于用户，插件不保存密码
- [ ] 浏览器会话丢失要明示，不能当没事发生
- [ ] 标签页操作不丢用户原有标签
- [ ] 多窗口/多实例不抢占用户当前窗口

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
