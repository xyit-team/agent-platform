# 插件 · 网页交互

| 项 | 值 |
|---|---|
| `id` | `browser-act` |
| 所属分类 | 操作 |
| 风险级别 | elevated（需确认） |
| 依赖插件 | `browser-open`、`action-authorize`、`web-read` |
| 状态 | ⬜ 待开发 |

## 1. 目标

网页上的填表、点击、选择、下载、上传。定位不到就停下来问，不乱点。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "browser-act",
  version: "0.1.0",
  description: "网页上的填表、点击、选择、下载、上传。定位不到就停下来问，不乱点。",
  capabilities: [/* 见 §4 */],
  permissions: ["device", "net"],
  requires: ["browser-open", "action-authorize", "web-read"],
  riskLevel: "elevated",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `fill(selector, value) => void`
- `click(selector) => void`
- `select(selector, option) => void`
- `upload(selector, fileRef) => void`
- `download(selector, destRef) => FileRef`
- `snapshot() => Element[]`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `device` | 控制鼠标键盘屏幕 | 是 |
| `net` | 调用模型与外部服务 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 元素定位失败 | 截图给用户指认，**不猜着点** |
| 表单有未知必填项 | 停下询问，不乱填 |
| 提交后无回执 | 报告状态不确定，**不假设成功** |
| 页面改版 | 重取快照，标明选择器已失效 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 定位失败不猜，停下问
- [ ] 填入内容提交前可预览给用户
- [ ] 提交结果以回执为准，不以点击成功为准
- [ ] 不把敏感信息填入非授权站点

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
