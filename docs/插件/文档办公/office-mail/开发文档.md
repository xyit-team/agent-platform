# 插件 · Outlook 邮件

| 项 | 值 |
|---|---|
| `id` | `office-mail` |
| 所属分类 | 文档办公 |
| 风险级别 | elevated（需确认） |
| 依赖插件 | 无 |
| 状态 | ⬜ 待开发 |

## 1. 目标

读邮件、发草稿。**不自动发送**。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "office-mail",
  version: "0.1.0",
  description: "读邮件、发草稿。**不自动发送**。",
  capabilities: [/* 见 §4 */],
  permissions: ["process", "net"],
  requires: [],
  riskLevel: "elevated",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `list(folder, query?) => MailItem[]`
- `read(id) => MailItem`
- `draft(mail) => DraftRef`
- `send(draftId, confirm) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `process` | 见目标所述用途 | 是 |
| `net` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 非 Windows | 不可用并明确说明 |
| 发信失败 | 草稿保留 |
| 凭据失效 | 提示重新授权 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 只能生成草稿
- [ ] **发送必须显式确认**
- [ ] 草稿可编辑可取消
- [ ] 邮件内容敏感时脱敏
- [ ] 发送全审计

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
