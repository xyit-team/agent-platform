# 插件 · 计算工具·构建

| 项 | 值 |
|---|---|
| `id` | `tool-build` |
| 所属分类 | 工具 |
| 风险级别 | elevated（需确认） |
| 依赖插件 | `tool-exec` |
| 状态 | ⬜ 待开发 |

## 1. 目标

执行构建。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "tool-build",
  version: "0.1.0",
  description: "执行构建。",
  capabilities: [/* 见 §4 */],
  permissions: ["process", "fs:write"],
  requires: ["tool-exec"],
  riskLevel: "elevated",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `build(target?, opts?) => BuildResult`
- `artifacts() => ArtifactRef[]`
- `clean() => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `process` | 见目标所述用途 | 是 |
| `fs:write` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 构建失败 | 返回失败原因与关键输出 |
| 依赖缺失 | 明确指出缺哪个 |
| 产物过大 | 归档而非内联 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 结果可判定通过/失败
- [ ] 失败保留完整错误
- [ ] 产物可归档带校验和
- [ ] 命令来自项目配置

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
