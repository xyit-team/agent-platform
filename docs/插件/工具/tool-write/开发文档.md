# 插件 · 编写工具

| 项 | 值 |
|---|---|
| `id` | `tool-write` |
| 所属分类 | 工具 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `fs` |
| 状态 | ⬜ 待开发 |

## 1. 目标

文件写入、代码生成。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "tool-write",
  version: "0.1.0",
  description: "文件写入、代码生成。",
  capabilities: [/* 见 §4 */],
  permissions: ["fs:read", "fs:write"],
  requires: ["fs"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `writeFile(path, content) => WriteResult`
- `generateCode(spec) => ArtifactSet`
- `applyEdit(path, edit) => WriteResult`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:read` | 见目标所述用途 | 是 |
| `fs:write` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 路径越界 | 拒绝并说明范围 |
| 文件被占用 | 重试后失败则报错 |
| 磁盘满 | 明确报错不静默截断 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 写入前可预览

- [ ] **越界路径被拒绝**
- [ ] 写入进日志埋点

- [ ] 单独装载本插件成功，单独禁用后其余正常
