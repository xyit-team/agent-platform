# 插件 · 本地终端调用

| 项 | 值 |
|---|---|
| `id` | `terminal` |
| 所属分类 | 基础 |
| 风险级别 | elevated（需确认） |
| 依赖插件 | 无 |
| 状态 | ⬜ 待开发 |

## 1. 目标

在受控下执行本地命令。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "terminal",
  version: "0.1.0",
  description: "在受控下执行本地命令。",
  capabilities: [/* 见 §4 */],
  permissions: ["process"],
  requires: [],
  riskLevel: "elevated",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `exec(cmd, opts?) => ExecResult`
- `which(bin) => string|null`
- `background(cmd) => ProcessHandle`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `process` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 命令超时 | 终止并报告已耗时 |
| 输出过大 | 截断并标记 truncated |
| shell 不可用 | 逐程序执行并说明差异 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 命令与参数分离，不做字符串拼接
- [ ] 默认非交互
- [ ] 超时强制终止
- [ ] 输出截断时明确标记
- [ ] 全部执行进日志埋点

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
