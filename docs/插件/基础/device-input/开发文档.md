# 插件 · 设备输入

| 项 | 值 |
|---|---|
| `id` | `device-input` |
| 所属分类 | 基础 |
| 风险级别 | safe（无风险） |
| 依赖插件 | 无 |
| 状态 | ⬜ 待开发 |

## 1. 目标

截图、剪贴板、设备输入的统一入口。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "device-input",
  version: "0.1.0",
  description: "截图、剪贴板、设备输入的统一入口。",
  capabilities: [/* 见 §4 */],
  permissions: ["device", "clipboard"],
  requires: [],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `capture(opts?) => ArtifactRef`
- `clipboard() => ClipboardContent`
- `key(opts?) => InputEvent`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `device` | 见目标所述用途 | 是 |
| `clipboard` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 权限被拒 | 禁用对应能力并提示授权方式 |
| 截屏失败 | 重试后明确报错 |
| 剪贴板为空 | 返回空而非报错 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。
