# 插件 · 本地语音识别

| 项 | 值 |
|---|---|
| `id` | `asr-local` |
| 所属分类 | 语音 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `local-model` |
| 状态 | ⬜ 待开发 |

## 1. 目标

4B 以下模型本地识别，断网可用、音频不出本机。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "asr-local",
  version: "0.1.0",
  description: "4B 以下模型本地识别，断网可用、音频不出本机。",
  capabilities: [/* 见 §4 */],
  permissions: ["device"],
  requires: ["local-model"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `listen(opts?) => SpeechResult`
- `onPartial(cb) => void`
- `stop() => void`
- `listModels() => LocalModel[]`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `device` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 模型未加载 | 明确告知并给出加载指引，不静默转云端 |
| 识别质量不足 | 提示用户改用键盘 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 音频**不出本机**且可验证
- [ ] 识别结果带置信度
- [ ] 低置信度触发澄清
- [ ] 断网可用
- [ ] 模型清单可枚举

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
