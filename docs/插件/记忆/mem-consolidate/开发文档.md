# 插件 · 阶段归纳

| 项 | 值 |
|---|---|
| `id` | `mem-consolidate` |
| 所属分类 | 记忆 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `mem-timeline`、`mem-onering` |
| 状态 | ⬜ 待开发 |

## 1. 目标

长期经历按月/阶段归纳成骨架。**归纳失败保留原文，不硬归纳。**

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "mem-consolidate",
  version: "0.1.0",
  description: "长期经历按月/阶段归纳成骨架。**归纳失败保留原文，不硬归纳。**",
  capabilities: [/* 见 §4 */],
  permissions: ["net", "fs:write"],
  requires: ["mem-timeline", "mem-onering"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `monthly(month) => Skeleton`
- `phase(range, name) => Skeleton`
- `merge(a, b) => Skeleton`
- `backfill(range) => Skeleton`
- `stability(skeleton) => number`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 调用模型与外部服务 | 是 |
| `fs:write` | 写文件与落盘 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 归纳失败 | 保留事件线原文，**不硬归纳** |
| 事件太少 | 不生成阶段，标明依据不足 |
| 与已有骨架冲突 | 并列，标注冲突 |
| 重复归纳 | 幂等，不叠加 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 归纳有依据（可回溯到事件）
- [ ] 依据不足时明说不足
- [ ] 归纳幂等，重复跑不叠加
- [ ] 阶段命名不由模型独自决定
- [ ] 长期骨架不因一次失败而损坏

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
