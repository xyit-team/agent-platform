# 插件 · TagMemo 标签网络

| 项 | 值 |
|---|---|
| `id` | `mem-taggraph` |
| 所属分类 | 记忆 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `mem-diary` |
| 状态 | ⬜ 待开发 |

## 1. 目标

标签共现网络 + 脉冲传播，建立**联想路径**。让"考试"能带出"压力"，不需要关键词命中。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "mem-taggraph",
  version: "0.1.0",
  description: "标签共现网络 + 脉冲传播，建立**联想路径**。让\"考试\"能带出\"压力\"，不需要关键词命中。",
  capabilities: [/* 见 §4 */],
  permissions: ["fs:write"],
  requires: ["mem-diary"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `tag(memoId, tag) => void`
- `cooccur(tagA, tagB) => number`
- `propulse(seed, depth) => MemoId[]`
- `path(tagA, tagB) => Tag[]`
- `decay(prune) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:write` | 写文件与落盘 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 网络过小 | **无联想结果，明确说明** |
| 脉冲环路 | 截断并标注 |
| 标签泛滥 | 剪枝，剪掉的记入埋点 |
| 传播超时 | 按当前深度返回，标注不完整 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 联想不需要关键词命中
- [ ] 传播深度有上限，不无限扩散
- [ ] 环路被截断并标注
- [ ] 联想结果标明路径（怎么连上的）
- [ ] 网络可剪枝，剪枝有记录

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
