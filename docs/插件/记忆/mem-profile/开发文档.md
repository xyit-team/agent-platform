# 插件 · 个人档案

| 项 | 值 |
|---|---|
| `id` | `mem-profile` |
| 所属分类 | 记忆 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `mem-extract` |
| 状态 | ⬜ 待开发 |

## 1. 目标

用户**明确告知**的偏好事实：饮食偏好、朋友的过敏忌口、常用服务、工作目标、购物偏好、日常安排。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "mem-profile",
  version: "0.1.0",
  description: "用户**明确告知**的偏好事实：饮食偏好、朋友的过敏忌口、常用服务、工作目标、购物偏好、日常安排。",
  capabilities: [/* 见 §4 */],
  permissions: ["fs:write", "fs:read"],
  requires: ["mem-extract"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `get(key) => Fact | null`
- `set(key, value, confirm) => Fact`
- `list(domain) => Fact[]`
- `confirm(factId) => Fact`
- `expire(factId) => void`
- `correct(factId, value) => Fact`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:write` | 写文件与落盘 | 是 |
| `fs:read` | 读文件与已有数据 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 与已有事实冲突 | 标冲突，**不自动覆盖** |
| 用户未确认 | 暂存为待确认，不进自动注入 |
| 存储不可用 | 不降级为明文，明确告知 |
| 敏感字段误入 | 立即隔离并报出 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 只记用户**明确告知**的，不从行为反推
- [ ] 每条事实带置信度和确认状态
- [ ] 过敏忌口这类高危信息**必须用户确认**
- [ ] 用户可随时改和删
- [ ] **敏感字段不出网**（无条件）

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
