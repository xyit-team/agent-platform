# 插件 · 冷知识库

| 项 | 值 |
|---|---|
| `id` | `mem-coldbase` |
| 所属分类 | 记忆 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `doc-store`、`web-read` |
| 状态 | ⬜ 待开发 |

## 1. 目标

百科、手册等**静态资料**。与热记忆平行运行，不混为一谈。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "mem-coldbase",
  version: "0.1.0",
  description: "百科、手册等**静态资料**。与热记忆平行运行，不混为一谈。",
  capabilities: [/* 见 §4 */],
  permissions: ["net", "fs:write"],
  requires: ["doc-store", "web-read"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `ingest(source) => Chunk[]`
- `query(q) => Chunk[]`
- `cite(chunkId) => Citation`
- `refresh(sourceId) => void`
- `coverage(topic) => Report`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 调用模型与外部服务 | 是 |
| `fs:write` | 写文件与落盘 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 检索为空 | 明确无结果，**不从热记忆编** |
| 来源失效 | 标记过期，不用过期内容作答 |
| 入库失败 | 记录失败项，不整批回滚 |
| 版本冲突 | 保留旧版并标版本 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 冷知识和热记忆**物理分开**
- [ ] 每条可回溯到出处
- [ ] 过期内容要标记
- [ ] 不与个人记忆混检
- [ ] 入库失败可重试，不丢

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
