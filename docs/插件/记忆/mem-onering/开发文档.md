# 插件 · OneRing 事件线

| 项 | 值 |
|---|---|
| `id` | `mem-onering` |
| 所属分类 | 记忆 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `mem-compress`、`doc-store`、`mem-window` |
| 状态 | ⬜ 待开发 |

## 1. 目标

跨窗口短期连续性：近期消息压缩成事件线。**换窗口后仍接得上。**

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "mem-onering",
  version: "0.1.0",
  description: "跨窗口短期连续性：近期消息压缩成事件线。**换窗口后仍接得上。**",
  capabilities: [/* 见 §4 */],
  permissions: ["fs:write", "fs:read"],
  requires: ["mem-compress", "doc-store", "mem-window"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `append(sessionId, events) => Ring`
- `read(ringId, range) => Event[]`
- `close(ringId) => RingId`
- `archive(ringId) => void`
- `current() => Ring`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:write` | 写文件与落盘 | 是 |
| `fs:read` | 读文件与已有数据 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 压缩失败 | 保留原始消息，**不丢** |
| 事件线过长 | 归档旧环，保留索引 |
| 跨窗口无环 | 从窗口记忆重建，不凭空续 |
| 时间线断裂 | 显式标记断点 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 换窗口后能接上同一件事
- [ ] 事件线只记发生了什么，不记寒暄
- [ ] 压缩失败不丢原始消息
- [ ] 断点显式标记，不假装连续

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
