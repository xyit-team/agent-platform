# 插件 · 事件线压缩

| 项 | 值 |
|---|---|
| `id` | `mem-compress` |
| 所属分类 | 记忆 |
| 风险级别 | safe（无风险） |
| 依赖插件 | —（仅依赖核心） |
| 状态 | ⬜ 待开发 |

## 1. 目标

近期消息 → 事件线。**保留"发生了什么"，丢弃寒暄。** 摘要质量要标明。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "mem-compress",

  capabilities: [/* 见 §4 */],
  permissions: ["net"],
  requires: [],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `compress(messages) => EventLine`
- `toEvents(text) => Event[]`
- `weight(event) => number`
- `quality(before, after) => Score`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 调用模型与外部服务 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 模型不可用 | 退化为摘要式截断，**标明质量下降** |
| 压缩丢失关键事实 | 回退到原文，明确告警 |
| 消息太少 | 不压缩，避免噪声 |
| 压缩出错 | 保留原文重来 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 压缩只保留事实，不保留语气
- [ ] 压缩质量有评分，劣质结果会标明
- [ ] 医疗/合规记录排除在压缩之外
- [ ] 压缩可回溯到原始消息
- [ ] 压缩结果进埋点

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
