# 插件 · 候选记忆抽取

| 项 | 值 |
|---|---|
| `id` | `mem-extract` |
| 所属分类 | 记忆 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `mem-profile`、`context-chain` |
| 状态 | ⬜ 待开发 |

## 1. 目标

从对话里抽候选记忆，带置信度，交用户确认。**不确定的宁可不抽。**

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "mem-extract",
  version: "0.1.0",
  description: "从对话里抽候选记忆，带置信度，交用户确认。**不确定的宁可不抽。**",
  capabilities: [/* 见 §4 */],
  permissions: ["net", "fs:write"],
  requires: ["mem-profile", "context-chain"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `extract(turn) => Candidate[]`
- `score(candidate) => number`
- `confirm(candidateId) => Fact`
- `reject(candidateId, reason) => void`
- `feedback(candidateId, accepted) => void`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 调用模型与外部服务 | 是 |
| `fs:write` | 写文件与落盘 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 模型不可用 | **不抽取，不写入** |
| 置信度低 | 不问，等积累到更高置信 |
| 抽取内容敏感 | 标记待人工审，不自动入档案 |
| 误抽 | 用户可一键否决并记入反馈 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 只抽用户明确说的，不猜
- [ ] 每条候选带置信度和理由
- [ ] 高置信也不自动入库（除非用户开了自动）
- [ ] 误抽可否决并影响后续
- [ ] 抽取动作本身可追溯

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
