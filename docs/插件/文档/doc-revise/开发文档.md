# 插件 · 人机双向修订

| 项 | 值 |
|---|---|
| `id` | `doc-revise` |
| 所属分类 | 文档 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `doc-store` |
| 状态 | ⬜ 待开发 |

## 1. 目标

人2传改/人2评论，Agent 接受或带理由拒绝。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "doc-revise",
  version: "0.1.0",
  description: "人2传改/人2评论，Agent 接受或带理由拒绝。",
  capabilities: [/* 见 §4 */],
  permissions: ["net", "fs:write"],
  requires: ["doc-store"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `edit(docId, ref, content, by) => Revision`
- `comment(docId, ref, content, by) => Revision`
- `resolve(revId, accept) => Resolution`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 见目标所述用途 | 是 |
| `fs:write` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| Agent 无法处理修订 | 明确说明并标记待人工 |
| 冲突修订 | 保留双方版本 |
| 存储不可用 | 降级并告知 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 人改文档 Agent 能评论
- [ ] 人评论 Agent 能接受或**带理由拒绝**
- [ ] 修订指向段落而非整篇
- [ ] **Agent 拒绝必须给理由**
- [ ] 不可静默忽略

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
