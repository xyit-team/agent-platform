# 插件 · Plan 模式增强

| 项 | 值 |
|---|---|
| `id` | `plan-mode` |
| 所属分类 | 文档 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `doc-store doc-askable goal-table` |
| 状态 | ⬜ 待开发 |

## 1. 目标

计划可被质询、修订、否决；勾选即批准并自动新建子智能体。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "plan-mode",
  version: "0.1.0",
  description: "计划可被质询、修订、否决；勾选即批准并自动新建子智能体。",
  capabilities: [/* 见 §4 */],
  permissions: ["net", "fs:write"],
  requires: ["doc-store doc-askable goal-table"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `draft(objective) => Plan`
- `question(planId, q) => Answer`
- `revise(planId, changes) => Plan`
- `reject(planId, reason) => void`
- `approve(planId) => SpawnRequest`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 见目标所述用途 | 是 |
| `fs:write` | 见目标所述用途 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 计划无法修订 | 明确说明原因 |
| 审批超期 | 标记失效并要求重新确认 |
| — | **审批不自动执行高危工具** |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 计划可被追问为什么这么拆
- [ ] 可被修订
- [ ] **可被否决**
- [ ] 勾选方案即批准
- [ ] **批准后自动新建子智能体，不要求切模式**
- [ ] 批准记录进日志埋点

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
