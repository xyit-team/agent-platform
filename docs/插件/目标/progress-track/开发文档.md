# 插件 · 进度跟踪

| 项 | 值 |
|---|---|
| `id` | `progress-track` |
| 所属分类 | 目标 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `action-plan`、`task-log`、`git` |
| 状态 | ⬜ 待开发 |

## 1. 目标

自动采集实际进度，与计划对比，产出偏差。采集不到就只报人工填报的，不假装有数据。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "progress-track",
  version: "0.1.0",
  description: "自动采集实际进度，与计划对比，产出偏差。采集不到就只报人工填报的，不假装有数据。",
  capabilities: [/* 见 §4 */],
  permissions: ["fs:read", "net"],
  requires: ["action-plan", "task-log", "git"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `collect(planId) => Progress`
- `compare(planId) => Deviation[]`
- `burndown(planId) => Series`
- `markStale(planId) => void`
- `report(planId) => ProgressReport`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:read` | 读文件与已有数据 | 是 |
| `net` | 调用模型与外部服务 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 无采集源 | 只报人工填报，**明确标注数据来源** |
| 数据陈旧 | 标注采集时间，过期数据不当作现状 |
| 采集失败 | 沿用上次值并标注为上次值 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 每条进度带采集时间和来源
- [ ] 偏差可追到具体步骤，不只给总百分比
- [ ] 过期数据明确标为过期
- [ ] 采集失败不伪造数据

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
