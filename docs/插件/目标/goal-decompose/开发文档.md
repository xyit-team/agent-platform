# 插件 · 目标拆解

| 项 | 值 |
|---|---|
| `id` | `goal-decompose` |
| 所属分类 | 目标 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `goal-store`、`debate` |
| 状态 | ⬜ 待开发 |

## 1. 目标

把长期目标拆成可执行步骤，每步带验证条件。拆不动就要求人工拆，不硬拆。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "goal-decompose",
  version: "0.1.0",
  description: "把长期目标拆成可执行步骤，每步带验证条件。拆不动就要求人工拆，不硬拆。",
  capabilities: [/* 见 §4 */],
  permissions: ["net", "fs:write"],
  requires: ["goal-store", "debate"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `decompose(goalId) => StepTree`
- `refine(stepId, granularity) => StepTree`
- `reDecompose(goalId, reason) => StepTree`
- `validateStep(step) => Validation`
- `proposeAlternatives(goalId) => StepTree[]`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `net` | 调用模型与外部服务 | 是 |
| `fs:write` | 写文件与落盘 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 模型不可用 | 不拆解，**要求人工拆**，不编步骤 |
| 拆解粒度过粗 | 要求细化到可验证的粒度 |
| 拆解与约束冲突 | 显式报冲突，不自行取舍 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 每步都有验证条件，没有验证条件的步骤不算拆开
- [ ] 拆解方案有分歧时走 debate 取一，不拍脑袋
- [ ] 重拆解保留旧版本，可回退
- [ ] 拆解不执行任何动作，只产出计划

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
