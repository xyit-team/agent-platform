# 插件 · 目标账本

| 项 | 值 |
|---|---|
| `id` | `goal-store` |
| 所属分类 | 目标 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `doc-store` |
| 状态 | ⬜ 待开发 |

## 1. 目标

长期目标的账本。目标跨会话存在，所以它必须落盘、有层级、有状态、挂里程碑。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "goal-store",
  version: "0.1.0",
  description: "长期目标的账本。目标跨会话存在，所以它必须落盘、有层级、有状态、挂里程碑。",
  capabilities: [/* 见 §4 */],
  permissions: ["fs:write", "fs:read"],
  requires: ["doc-store"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `upsert(goal) => Goal`
- `get(goalId) => Goal | null`
- `list(filter) => Goal[]`
- `setStatus(goalId, status) => Goal`
- `linkMilestone(goalId, milestoneId) => Goal`
- `archive(goalId, reason) => Goal`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:write` | 写文件与落盘 | 是 |
| `fs:read` | 读文件与已有数据 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 无持久化 | 退化为内存态>会话结束即丢，**明确告警** |
| 并发写冲突 | 拒绝后写，不静默覆盖 |
| 目标层级成环 | 拒绝并报出环路径 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 目标有唯一 id，跨窗口同一目标指向同一条记录
- [ ] 状态流转合法（不允许 草稿 直接跳 已完成）
- [ ] 归档后不删除，保留可追溯
- [ ] 是公文式汇报第 1/2/3 段的数据源之一

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
