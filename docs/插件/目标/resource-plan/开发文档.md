# 插件 · 资源安排

| 项 | 值 |
|---|---|
| `id` | `resource-plan` |
| 所属分类 | 目标 |
| 风险级别 | safe（无风险） |
| 依赖插件 | `action-plan`、`agent-pool` |
| 状态 | ⬜ 待开发 |

## 1. 目标

人、预算、工具、算力的分配与冲突检测。超配要报出来，不自动削减。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "resource-plan",
  version: "0.1.0",
  description: "人、预算、工具、算力的分配与冲突检测。超配要报出来，不自动削减。",
  capabilities: [/* 见 §4 */],
  permissions: ["fs:write"],
  requires: ["action-plan", "agent-pool"],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `allocate(planId, resource) => Allocation`
- `checkConflict(planId) => Conflict[]`
- `rebalance(planId) => Plan`
- `release(planId, resourceId) => void`
- `forecast(planId, horizon) => Forecast`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| `fs:write` | 写文件与落盘 | 是 |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 无资源数据 | 只给相对优先级，**明确说明不是绝对分配** |
| 资源超配 | 显式报出不自动削减 |
| 实时资源不可得 | 用上一次快照，标注快照时间 |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 超配被报出，不静默削减
- [ ] 分配结果可解释（说得出为什么这样分）
- [ ] 释放资源后冲突自动消解
- [ ] 不直接调度人，只产出建议

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
