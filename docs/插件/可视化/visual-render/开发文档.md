# 插件 · 可视化渲染

| 项 | 值 |
|---|---|
| `id` | `visual-render` |
| 所属分类 | 可视化 |
| 风险级别 | safe（无风险） |
| 依赖插件 | 无 |
| 状态 | ⬜ 待开发 |

## 1. 目标

把结构化数据渲染成图（依赖图/组件树/任务池）。

## 2. 归属理由

**不进核心。** 核心不依赖插件；拿掉本插件，系统照常启动，只是少这一项能力。

## 3. 清单

```ts
import type { PluginManifest } from "@core/types";

export const manifest: PluginManifest = {
  id: "visual-render",
  version: "0.1.0",
  description: "把结构化数据渲染成图（依赖图/组件树/任务池）。",
  capabilities: [/* 见 §4 */],
  permissions: [],
  requires: [],
  riskLevel: "safe",
  healthCheck: { command: "node -e \"require('./dist')\"", timeoutMs: 3000 },
};
```

## 4. 接口契约

```ts
// 由本插件导出，整合包只依赖这些能力
- `render(data, type) => View`
- `layouts() => LayoutKind[]`
- `sample(data, n) => View`
```

**契约要求**：
- 输入输出用 `SchemaRef` 声明，运行时校验
- 失败时抛 `PluginError`（带 `code`），由装载器捕获，**不上抛到主循环**
- 能力被单独关掉时，其余插件不受影响

## 5. 权限

| 权限 | 理由 | 必需 |
|---|---|---|
| — | 不需要权限 | — |

**实际可用 = 本插件声明 ∩ 整合包授权。** 本插件多声明无效。

## 6. 降级策略

| 情况 | 行为 |
|---|---|
| 无图形环境 | 降级为文本呈现 |
| 渲染失败 | 降级文本，**不丢内容** |
| 数据量过大 | 降采样并**明确说明是采样结果** |

**通用原则**：降级必须可见。不可用就是不可用，用户要知道原因。

## 7. 验收

- [ ] 同一对象可在文本/图形间切换
- [ ] 渲染失败时内容不丢
- [ ] 降采样时明确标注
- [ ] 敏感字段自动脱敏
- [ ] 万级节点可交互

- [ ] 全部操作进日志埋点（模型路径可追踪）
- [ ] 单独装载本插件成功，单独禁用后其余正常
