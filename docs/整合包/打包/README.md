# 打包

> 打包成 zip 的**整合包**和**插件**放这里。
> 装载器从文件夹或 zip 装载，**两者等价**（见 [../开发文档.md §10](../开发文档.md)）。

## 1. 目录

```text
打包/
├── README.md                        ← 本文件
├── 整合包/
│   ├── 语音助手-0.1.0.zip
│   └── 代码开发-0.1.0.zip
└── 插件/
    ├── cursor-sprite-0.1.0.zip
    └── asr-local-0.1.0.zip
```

**命名**：`{id}-{version}.zip`。`id` 见各插件/整合包清单的 `id` 字段。

## 2. 插件 zip

zip 里是**一个插件的完整目录**：

```text
asr-local-0.1.0.zip
├── 清单.ts            ← PluginManifest
├── 开发文档.md
├── dist/              ← 编译产物
│   ├── index.js
│   └── index.d.ts
└── package.json
```

| 要求 | 说明 |
|---|---|
| 必含 `dist/` | 装载器不编译，只装载产物 |
| 必含 `package.json` | 声明依赖与 `main` |
| 依赖需声明 | 未声明的依赖装载时按缺失处理 |
| 可含 `开发文档.md` | 便于审阅，不参与运行 |

## 3. 整合包 zip

zip 里是**一个整合包的完整目录**：

```text
语音助手-0.1.0.zip
├── 清单.ts            ← IntegrationPackageManifest
├── 开发文档.md
├── 提示规则/
├── 汇报格式.ts
├── 状态机.ts
└── package.json
```

| 要求 | 说明 |
|---|---|
| 必含 `清单.ts` | 否则无法装载 |
| 必含 `提示规则/` | 缺失则用核心兜底并告警 |
| 必含 `汇报格式.ts` | 缺失则退回核心默认三段式并告警 |
| `transitions` 非空 | **校验错误，无交接声明 = 未完成** |

## 4. 装载前校验

zip 丢进 `打包/` 后，装载器装载时先跑 `validate()`（见 [../开发文档.md §8](../开发文档.md)）：

| 结果 | 行为 |
|---|---|
| 无错误 | 装载 |
| 有警告 | **装载**，记入日志埋点，首次使用时提示 |
| 有错误 | **拒绝装载**，列出全部问题 |

> 校验不通过的 zip 会留在原地，便于改完重打。

## 5. 打包约定

| 约定 | 理由 |
|---|---|
| 产物 `dist/` 一并打包 | 装载器不编译 |
| 清单用裸 `id` | 见 [../../插件/README.md §5](../../插件/README.md) |
| 版本号用语义化版本 | 装载器按 `id` 匹配，版本仅记录 |
| 不打包依赖 | 依赖由 `package.json` 声明，缺失即降级 |
| zips 不进版本库 | 产物，用 `.gitignore` 排除 |
