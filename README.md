# agent-platform

A multi-functional, customized, out-of-the-box intelligent agent platform.

> **一个主核心单薄、其余皆为插件的 Agent 平台。** 底座只负责装载、路由、记录；用户操作的是整合包（模式）；能力来自本地插件和云端套件；模式之间可时空衔接。
>
> **本仓库当前只有文档，没有实现代码。** 里面的 TypeScript 是接口契约的规格说明，不是可编译的源码。

## 三条最要紧的

1. **主核心单薄** —— 拿掉全部插件，核心仍能启动。判据是「**拿掉它系统还能不能跑**」，不是「有没有模式用它」。
2. **全部内容只提供接口** —— 包括转化器在内的一切都允许替换，替换走适配器注册不走代码分支。
3. **降级不静默** —— 云端不可用、工具离线、权限不足，一律明确告知原因，不悄悄换个近似的顶上。

冲突时怎么裁决见 [11 §4](开发文档/11-设计理念与硬性约束.md)。
